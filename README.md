# 우테코 2주차 : 자동차 경주

## 핵심 구현 필요 사항

1. 경주할 자동차들에 이름 부여하기<br>
   1-1. 자동차들의 이름은 쉼표를 기준으로 구분될 수 있도록 한다.<br>
   1-2. 자동차들의 이름은 5자 이하로 제한한다.
2. 출력 시, 전진하는 자동차의 이름이 같이 출력될 수 있도록 한다.
3. 출력 시, 자동차 경주 완료 후 사용자 입력한 전진 수에 먼저 도달한 자동차가 우승이 될수 있게 한다.<br>
   3-1. 우승자는 여러 명이 될 수 있다.
4. 입력 시, 사용자가 자동차가 몇 번의 이동을 할 것인지 입력할 수 있도록 한다.
5. 전진 조건, 무작위 값이 4이상인 경우 전진한다
   4-1. 0~9 무작위 수를 생성한다.
   4-2. 무작위 값이 4미만인 경우 정지한다.
